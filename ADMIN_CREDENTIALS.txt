 How to log in
=============================================

1. Start XAMPP → click [Start] next to MySQL
2. Start the backend:
     cd "d:\Finance mgmt app"
     python main.py
3. Start the frontend:
     cd "d:\Finance mgmt app\frontend"
     npm run dev
4. Open http://localhost:5173
5. On the login page, enter the username "admin" and password "admin123",
   then press Sign In.

=============================================
 Notes
=============================================

- The admin account is seeded automatically
  on every backend startup via ensure_admin_exists().
- If you ever reset the DB, just restart the
  backend and the admin is recreated fresh.
- To change the admin password, update
  ADMIN_PASSWORD in auth.py (line 12) and
  restart the backend.
